# first-claud-game

A noughts and crosses (tic-tac-toe) game written in C++.

## Build

```bash
g++ -o noughts_and_crosses noughts_and_crosses.cpp
```

## Play

```bash
./noughts_and_crosses
```

Players take turns entering a position (1-9) based on the grid:

```
1 | 2 | 3
---------
4 | 5 | 6
---------
7 | 8 | 9
```
