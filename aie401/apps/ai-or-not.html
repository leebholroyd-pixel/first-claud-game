AI or Not?

Twelve everyday tools. For each one, decide what is really going on underneath: machine learning, generative AI, an adaptive system, or plain automation. Build a streak.

Machine learning
Learns patterns from data to predict or classify
Generative AI
Produces new text, images, audio or code
Adaptive system
Changes what a learner sees next based on performance
Automation
Follows fixed rules, no learning involved
